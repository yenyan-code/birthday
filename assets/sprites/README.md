# Sprites Directory

The game features built-in high-performance **procedural pixel art rendering** generated dynamically on HTML5 Canvas in `src/js/engine.js`. This guarantees razor-sharp rendering on all screen resolutions and removes external image loading dependencies.

### Custom Sprite Drop-in Support:
You can drop custom `.png` sprite sheets into this folder to replace the procedural renderers:
* `player.png` — Aloy runner sprite sheet (48×68px frames).
* `askal.png` — Philippine street dog sprite sheet (54×38px).
* `tricycle.png` — Parked tricycle sprite sheet (78×68px).
* `pothole.png` — Road hazard sprite (50×20px).
* `coin.png` — Gold peso coin spinning sprite (24×24px).
* `cake.png` — Celebration birthday cake with flickering candles.
